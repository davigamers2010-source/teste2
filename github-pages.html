Esta página está no GitHub Pages. O GitHub Pages publica o site, mas não executa o servidor necessário para login, cadastro e autorização da Shopee.

O endereço do servidor ainda não foi configurado. Por isso, a tela anterior mostrava “Servidor desligado” e não oferecia login.
Tentar conectar no servidor deste computador

Esse botão só funciona se a Central estiver iniciada neste computador. Para acessar pela internet, publique o backend Node.js e configure em backend-config.js a URL HTTPS pública do serviço.

  1. No backend-config.js, defina window.CENTRAL_BACKEND_URL com a URL HTTPS do backend — não coloque senhas, tokens ou chaves nesse arquivo.
  2. Envie os arquivos atualizados ao repositório e aguarde o GitHub Pages publicar.
  3. Abra novamente o endereço GitHub Pages. Ele encaminhará para o servidor, onde você poderá entrar ou criar uma conta.
